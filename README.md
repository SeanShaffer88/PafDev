# PafDev — PortableApps.com Development Knowledge Base

## TL;DR

This repository is a complete, self-contained reference for creating
PortableApps.com Format (`.paf.exe`) packages: the directory layout, the
`appinfo.ini` and `installer.ini` files, the PortableApps.com Launcher (PAL)
and its `launcher.ini`, the PortableApps.com Installer, custom NSIS code,
testing, debugging, licensing, and submission. It is written so that an AI
assistant (or a human developer) can learn the whole process from this repo
alone and then create, code, compile, and test a correct PortableApps.com
package without inventing any settings.

Current official versions this knowledge is based on (checked 2026-11-16):

| Thing | Version | Date |
|---|---|---|
| PortableApps.com Format | 3.9 | 2026-03-02 |
| PortableApps.com Launcher (PAL) | 2.2.9 | 2024-05-25 |
| PortableApps.com Installer | 3.9.18 | 2026-07-20 |
| PortableApps.com Application Template | 3.9.2 | 2026-07-11 |

Sources are listed in [SOURCES.md](SOURCES.md). Where this repo and the
official specification disagree, the official specification wins.

## How an AI should use this repo

1. Read [AGENTS.md](AGENTS.md) first — it contains the non-negotiable rules
   (never invent INI keys, exact version formats, the build order, and the
   verification steps).
2. Read [docs/01-format-spec.md](docs/01-format-spec.md) for the package
   layout and `appinfo.ini`.
3. Read [docs/03-launcher-overview.md](docs/03-launcher-overview.md) and
   [docs/04-launcher-ini-reference.md](docs/04-launcher-ini-reference.md)
   before writing any `launcher.ini`.
4. Read [docs/02-installer-and-installer-ini.md](docs/02-installer-and-installer-ini.md)
   before writing any `installer.ini` or building a `.paf.exe`.
5. Follow [docs/07-end-to-end-workflow.md](docs/07-end-to-end-workflow.md)
   as the step-by-step build procedure.
6. Copy from [templates/](templates/) and [examples/](examples/) instead of
   writing configuration files from memory — or scaffold with
   [tools/new-package.sh](tools/) and validate with
   `tools/check-package.py` as you go.
7. Run through [checklists/pre-release-checklist.md](checklists/pre-release-checklist.md)
   before calling a package done.

## Using this repo with ChatGPT or another AI, locally

This repo is built to be downloaded and used offline by an AI:

1. Download the repo (Code → Download ZIP) and unzip it anywhere.
2. Point the AI at the folder. It should start with
   [manifest.json](manifest.json) (the file map and reading order)
   and [AGENTS.md](AGENTS.md) (the rules), then read in the manifest's
   order.
3. No time to load a folder? Upload [ai-bundle.md](ai-bundle.md)
   instead — the entire knowledge base concatenated into one markdown
   file. (Generated by [tools/build-ai-bundle.py](tools/); the bundle
   covers the docs and references — templates, tools, and example
   configs stay as files, listed in the manifest.)

Everything is plain text/markdown with relative links; nothing here
needs a server, an account, or this repository's website.

## The 30-second model

A PortableApps.com package is a folder named `AppNamePortable`:

```
AppNamePortable\
  AppNamePortable.exe        <- generated launcher (compiled by PAL)
  help.html
  App\
    AppInfo\                 <- appinfo.ini, installer.ini, icons, Launcher\
    AppName\                 <- the actual application binaries
    DefaultData\             <- first-run defaults copied into Data\
  Data\                      <- ALL user data and settings live here
  Other\
    Help\Images\
    Source\                  <- launcher readme, licenses, custom code
```

Three configuration files drive everything:

- `App\AppInfo\appinfo.ini` — tells the PortableApps.com Platform what the
  app is (name, ID, version, category, license, dependencies).
- `App\AppInfo\Launcher\AppNamePortable.ini` — tells the generated launcher
  how to make the app portable (what to move, redirect, back up, restore).
- `App\AppInfo\installer.ini` — (optional) tells the PortableApps.com
  Installer how to build/install the package (downloads, extraction,
  optional components, upgrade behaviour).

Two official tools compile the deliverables:

- The **PortableApps.com Launcher Generator** reads the launcher INI and
  compiles `AppNamePortable.exe` with NSIS.
- The **PortableApps.com Installer** wizard reads `appinfo.ini` +
  `installer.ini` and compiles the distributable `AppNamePortable_X.Y.paf.exe`.
