AppName Portable Help

AppName Portable is a portable version of AppName. It stores all of its settings and data inside its own Data folder, so it can be carried on a portable drive and used on any Windows PC without leaving settings behind on the host computer.

Running AppName Portable

Run AppNamePortable.exe. On first run, default settings are created in the Data folder. Deleting the Data folder resets the app to its defaults.

Your data, backups, and privacy

Everything this app remembers lives in the Data folder, in plain form, like most applications' settings. Copying the whole AppNamePortable folder copies the app and your data; copying just Data backs up your settings and data. If you carry accounts or credentials in this app, consider encrypting the drive (for example with BitLocker To Go) — a lost drive otherwise means lost accounts. If you run this app on a shared or public computer, the app restores the computer's own settings when it closes — but anything you save outside the app (for example a file you export to the Desktop) stays where you put it. The extracted package folder is program files: if anyone else could have changed files in it, delete it and re-install from the original .paf.exe.

User configuration

An optional configuration file can be placed next to AppNamePortable.exe. Copy Other\Source\AppNamePortable.ini to the package root, rename it to AppNamePortable.ini, and edit it. Supported options:

  • AdditionalParameters= — extra command-line parameters passed to the application.
  • DisableSplashScreen=false — set to true to hide the splash screen.
  • RunLocally=false — set to true to run from read-only media; the app is copied to a temporary folder, run, and the copy is removed afterwards.
